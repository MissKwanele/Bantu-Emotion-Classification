🌍 Bantu Emotion Classification

This research project explores multilingual emotion classification using transformer models for isiZulu, isiXhosa and Swahili.

📌 Highlights

  • AfriBERTa, XLM-R, Serengeti fine-tuned on emotion datasets
  • Multilabel classification with six emotion tags
  • Logged experiments with Weights & Biases
  • Focus on low-resource Bantu languages
